# Общее описание решения

> **Цель проекта:** продемонстрировать документирование ИТ-продукта средствами Markdown.

## Что делает проект

Библиотека геометрических вычислений. Содержит функции для расчёта площади и периметра четырёх геометрических фигур:

- **Круг** (`circle.py`) — площадь и длина окружности
- **Прямоугольник** (`rectangle.py`) — площадь и периметр
- **Квадрат** (`square.py`) — площадь и периметр
- **Треугольник** (`triangle.py`) — площадь и периметр
