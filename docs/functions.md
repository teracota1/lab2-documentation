# Описание функций

В проекте реализованы функции для расчёта площади и периметра четырёх фигур. Каждая функция содержит docstring с описанием, параметрами и примером вызова.

## Круг (`circle.py`)

### `area(r)`

Возвращает площадь круга.

**Параметры:**
- `r` (*float*) — радиус круга

**Возвращает:** `float` — площадь круга

**Формула:** π · r²

**Пример вызова:**
```python
from circle import area

area(1)  # 3.141592653589793
```

### `perimeter(r)`

Возвращает длину окружности.

**Параметры:**
- `r` (*float*) — радиус круга

**Возвращает:** `float` — длина окружности

**Формула:** 2 · π · r

**Пример вызова:**
```python
from circle import perimeter

perimeter(1)  # 6.283185307179586
```

## Прямоугольник (`rectangle.py`)

### `area(a, b)`

Возвращает площадь прямоугольника.

**Параметры:**
- `a` (*float*) — первая сторона
- `b` (*float*) — вторая сторона

**Возвращает:** `float` — площадь

**Формула:** a · b

**Пример вызова:**
```python
from rectangle import area

area(2, 3)  # 6
```

### `perimeter(a, b)`

Возвращает периметр прямоугольника.

**Параметры:**
- `a` (*float*) — первая сторона
- `b` (*float*) — вторая сторона

**Возвращает:** `float` — периметр

**Формула:** 2·a + 2·b

**Пример вызова:**
```python
from rectangle import perimeter

perimeter(2, 3)  # 10
```

## Треугольник (`triangle.py`)

### `area(a, h)`

Возвращает площадь треугольника через сторону и высоту.

**Параметры:**
- `a` (*float*) — сторона треугольника
- `h` (*float*) — высота, проведённая к стороне `a`

**Возвращает:** `float` — площадь

**Формула:** a · h / 2

**Пример вызова:**
```python
from triangle import area

area(2, 3)  # 3
```

### `perimeter(a, b, c)`

Возвращает периметр треугольника.

**Параметры:**
- `a` (*float*) — первая сторона
- `b` (*float*) — вторая сторона
- `c` (*float*) — третья сторона

**Возвращает:** `float` — периметр

**Формула:** a + b + c

**Пример вызова:**
```python
from triangle import perimeter

perimeter(1, 2, 3)  # 6
```
